## Purpose
Folder where all modules are created, used to modularise the application and keep app.module.ts as clean as possible.
Each of them is related to the components/directives/services declared in the folder with the same name.

E.g.: layouts.module.ts has all the components in the folder named "layouts".

### Special case

- **layout-components.ts:** This file is where the components used in the layouts, e.g. skills, items, notes, etc., are declared.
